# Identidad visual del producto

Esta es la parte menos técnica y más de diseño/branding — importa
porque el público objetivo son niños, y un mueble sin identidad visual
atractiva no genera el mismo interés que uno con colores y un nombre
propios.

**[PROPUESTA — para que el equipo la discuta y ajuste, no es una
decisión final]**

## Nombre propuesto

**"Consola Arcade 4x1"** como nombre técnico de trabajo (ya usado en
todo el repo) — como nombre de producto de cara al público, se propone
algo más llamativo para niños, por ejemplo:

- **"ArcadeFPGA"**
- **"Tetra-Play"** (por los 4 jugadores/pantallas simultáneas)
- **"PixelBox"**

(Cualquiera de los tres funciona — es una decisión de equipo, no
técnica; elegir el que más les guste o proponer otro.)

## Paleta de colores propuesta

Pensada para ser vibrante y amigable para niños, sin ser tan saturada
que canse la vista en uso prolongado:

| Color | Uso |
|---|---|
| Azul eléctrico `#1E88E5` | Color principal del gabinete (pintura o vinilo) |
| Amarillo vivo `#FDD835` | Detalles, marco de las pantallas, botones "Start" |
| Rojo coral `#E53935` | Botones de acción (ya coincide con el color real de los botones arcade elegidos en el BOM) |
| Blanco/gris claro `#F5F5F5` | Fondo de las gráficas/logo, para contraste |

## Método de aplicación real (según presupuesto y herramientas disponibles)

1. **Pintura**: la opción más barata. Pintura acrílica para madera,
   aplicada sobre el MDF ya lijado y con base selladora (el MDF sin
   sellar absorbe la pintura de forma irregular).
2. **Vinilo adhesivo cortado**: si la universidad tiene un plotter de
   corte (común en un fablab), se pueden hacer logos y gráficas más
   nítidas que a mano. Más caro que pintura pero con mejor acabado.
3. **Gráficas impresas + laminado**: imprimir el diseño en una
   impresora normal/gran formato, laminarlo (mica adhesiva) para
   protegerlo, y pegarlo sobre el MDF pintado de un color base. Buen
   punto medio entre costo y acabado.

## Elementos gráficos sugeridos

- Logo del proyecto en la parte frontal superior (visible de lejos).
- Nombre de cada juego (Pong, Space Invaders, Snake, Carrito) rotulado
  cerca de su pantalla correspondiente — ayuda a que un niño sepa qué
  va a jugar antes de acercarse.
- Iconos simples de las 8 direcciones/botones sobre o cerca de cada
  control (referencia visual rápida, sin necesitar leer).
